# PCAP Quest 🐍

A study app to pass the **PCAP (Certified Associate Python Programmer)** exam in two weeks: a daily plan, whiteboard "teacher mode" lessons, verified quizzes, weak-spot tracking, timed mock exams and an in-browser Python lab, wrapped in a game (XP, levels, streaks, badges).

> Not affiliated with or endorsed by the OpenEDG Python Institute. "PCAP" is their certification; this is an independent study aid. Lessons follow the *Python Essentials 2* course.

## Features

| | |
|---|---|
| **Today** | 14-mission plan to the exam date, a 15-minute daily goal ring, streak, estimated exam readiness weighted like the real exam |
| **Teacher mode** | Whiteboard lessons that build up step by step: hand-drawn diagrams, circled traps, code with notes, a "your turn" question per board |
| **Learn** | Lessons for every exam section (Modules, Strings, Exceptions, OOP, Miscellaneous, plus the PCAP-31-04 extras) |
| **Practice** | 145 exam-style multiple-choice questions, each with a full explanation; 200+ notebook flashcards; redo-my-mistakes with spaced repetition |
| **Mock exams** | 40 questions · 65 minutes · section breakdown · 70% pass line |
| **Weak spots** | Mastery heat map across 29 topics, with one-tap drills on the weakest |
| **Code lab** | Python in the browser (Brython), lazy-loaded |
| **Themes** | White, Dark, Night (warm, dim) and Auto (Night from 21:00 to 07:00) |

## Every answer is checked with real Python

The content is generated by the scripts in `build/`. Each one **runs every code snippet in CPython** and stops if any written answer differs from the real output, so no quiz answer is typed from memory.

```bash
pip install weasyprint            # only needed for the PDF notebooks
cd build
python3 export.py                 # notebooks 1–6 → lessons + flashcards (verified)
python3 mcq.py                    # multiple-choice bank (verified)
python3 explain.py                # explanations
python3 boards.py                 # teacher-mode whiteboards (verified)
python3 make_content.py           # → app/content.json
python3 nb4.py ../notebooks/PCAP_4_OOP.pdf   # rebuild one PDF notebook
```

## Run the app locally

```bash
cd app
python3 -m http.server 8000
# open http://localhost:8000
```

Progress is saved in the browser (`localStorage`). When opened as a Claude artifact, it also syncs between devices and can read the teacher boards aloud.
